# ESP32-S3-N16R8 開發板規格

實際板子（果云 ESP32-S3 開發板，配對的原理圖/腳位圖見同目錄 `ESP32-S3-N16R8果云開發板原理圖.pdf` / `...腳位圖.jpg`）用 `esptool` 直接讀晶片確認過的硬體資訊，不是查文件猜的。

## 查詢方式

```
uvx esptool --port <COMx> flash-id
```

## 對應的 PlatformIO 板子設定

`platformio.ini` 原本 `env:s3` 用的 `board = esp32-s3-devkitc-1` 是 PlatformIO 內建的泛用設定,預設當作 **8MB flash、無 PSRAM** 的板子——分區表照 8MB 切、PSRAM 完全沒宣告啟用，跟這片板子實際的 16MB flash + 8MB PSRAM 不符。

已於 2026-08-12 修正為：

```ini
board = esp32-s3-devkitc1-n16r8
```

這個板子定義（pioarduino fork 內建）會正確帶入：
- `partitions = default_16MB.csv`（16MB flash 分區表)
- `-DBOARD_HAS_PSRAM`、`memory_type = qio_opi`（啟用 8MB Octal PSRAM)
- `upload.flash_size = 16MB`

修正後建置結果：Flash 可用空間從 3,342,336 bytes（~3.3MB,舊的 8MB 分區表換算)變成 6,553,600 bytes（~6.25MB,新的 16MB 分區表),同一份韌體用量比例從 40.2% 降到 20.6%。已在實機上驗證燒錄後開機、螢幕顯示正常。

**注意**：PSRAM 目前只是「啟用/可用」，程式碼裡還沒有任何地方主動配置到 PSRAM 上（例如用 `ps_malloc()`/`heap_caps_malloc(MALLOC_CAP_SPIRAM, ...)`）——現有的 RAM 用量數字（約 61KB/320KB)指的都還是內部 SRAM,8MB PSRAM 是額外可用但目前完全閒置的空間,以後如果需要更大的緩衝區可以善用。
